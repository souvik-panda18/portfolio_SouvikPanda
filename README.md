# 🚀 Souvik Panda – Personal Developer Portfolio

A modern, responsive, and interactive personal portfolio website, built with **HTML5**, **Tailwind CSS**, and vanilla JavaScript. Showcases my projects, skills, resume, and social links, with a fresh UI, dark mode, glassmorphism, and dynamic backgrounds.

---

## ✨ Features

- 📱 **Responsive Design:** Looks great on desktop and mobile devices.
- 🌗 **Dark/Light Mode Support:** Automatic or manual color scheme switching.
- 🖼️ **Project Showcase:** Gallery with screenshots, live links, and detailed descriptions.
- 👋 **Animated Hero Section:** Introduces you with custom animation.
- 🧑‍💻 **Skills Overview:** Categorized grid with ratings.
- 📄 **Downloadable Resume:** Easy access to professional CV.
- 🔗 **Contact & Social Links:** Footer with active social network and contact integration.
- 🎨 **Modern Styling:** Uses Tailwind CSS utility classes and a custom full-background image.
- 📌 **NavBar Anchors:** Navigation links scroll to home/skills/projects/contacts sections smoothly.
- ♿ **Accessible:** Semantic HTML with accessible color contrasts and keyboard navigation.

---

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS** (CDN)
- **Vanilla JavaScript**
- **Font Awesome**
- 🤖 **AI-Generated Images** for project illustrations

---

## 🏗️ Getting Started

1. **Clone the repo:**

   ```
   git clone https://github.com/souvik-panda18/portfolio.git
   cd portfolio
   ```

2. **Add your assets:**
   - Place your profile image, background images, and project images in the root or `/assets` folder.
   - Update filenames in the HTML if needed.

3. **Open in a browser:**
   - Open `index.html` directly.
   - No build tools required! Deployed version works on GitHub Pages, Netlify, or Vercel with no backend.

## ⚙️ Customization

- 🏆 **Projects:** Edit the Projects section in `index.html` for updates, additions, or removals. Each supports an image and colored border.
- 🎨 **Theme:** Update the global background via `yourbackground.jpg` or another image in the `` class.
- 🌘 **Dark Mode:** Supported via Tailwind’s `dark:` classes.
- 🔗 **Navbar Anchors:** Anchor tags `` connect to relevant `` blocks for smooth scrolling.
